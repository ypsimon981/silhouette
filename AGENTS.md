# 10Potatoes visual scope

All future cosmetic changes apply only to potato levels. Animal and flower levels must retain their existing appearance. Guard rendering changes with the game's `isSilhouetteMode(mode)` exclusion, and scope CSS so both `.level-animals` and `.level-flowers` are excluded. Verify both non-potato modes when changing shared rendering code.

This rule starts with the flour-target change. Do not retroactively revert previously approved shared sizing or backgrounds as part of an unrelated cosmetic task.

Explicit exception approved by the user: the photographic potato START and 3–2–1 countdown artwork is shared by all levels, including animals and flowers. This exception does not extend to pieces, flour targets or other future cosmetic changes.

Explicit animal-only exception: a neutral, low-contrast tone-on-tone animal-footprint background is approved for the Animals level. This changes its background only; its pieces/targets and the Flowers level retain their existing appearance.

Explicit flower-only exception: a dark-green fine grass texture is approved as the Flowers background. Target edge contrast may be adjusted for readability, while preserving the exact paths, pieces and gameplay. Other modes keep their approved backgrounds.
